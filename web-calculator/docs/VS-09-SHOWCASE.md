# VS-09 Calculation History: Showcase Guide

Use this to demo the calculation history feature to stakeholders (about 3 minutes).

## Before You Start

1. **Open the app**  
   Open `index.html` in a browser (e.g. double-click or `open web-calculator/index.html` from the repo root).

2. **Optional backup**  
   Record a short screen capture of the flow in case the live demo fails (see [showcasing-features.instructions.md](../../.github/instructions/showcasing-features.instructions.md)).

---

## 3-Minute Script

| Step | What to do | What to say |
|------|------------|-------------|
| **1. Show feature** | Click **History** → panel slides in | *"Your calculation history lives here."* |
| **2. Build history** | Do **5 + 3 =**, **10 × 2 =**, **100 ÷ 4 =** | *"Each result is automatically tracked."* |
| **3. Recall value** | Click the **"5 + 3 = 8"** item in the list | *"Click any entry to recall that result."* |
| **4. Continue from history** | With **8** on the display, press **× 2 =** | *"You can build on previous work—e.g. 16."* |
| **5. Persistence** | Refresh the page | *"History persists across sessions."* |
| **6. Clear option** | Click **Clear History** | *"You can start fresh whenever you need to."* |
| **7. Keyboard** | Tab to **History** → Enter to open; Tab to an item → Enter to recall | *"Fully usable from the keyboard."* |

**Key message to close:**  
*"Never lose track of your work—full calculation history with easy recall."*

---

## Q&A Preview

| Question | Answer |
|----------|--------|
| Can I edit history? | No—it’s read-only. Expression editing is planned in VS-15. |
| Can I export history? | Yes—CSV/text export is planned in VS-19. |
| Why only 20 items? | Balances usefulness and clutter; may become configurable later. |
